# HALVETH x xAI - USD 40M Bounded Collaboration Proposal

**Concise project guide · EN / RU**

A public proposal for a staged research collaboration with a program ceiling of USD 40,000,000. The documents set out an exploratory conversation, a bounded evaluation capsule and possible later milestones under written agreement.

The amount is a proposed ceiling, not an awarded contract, accepted offer or debt owed to HALVETH. The published snapshot records external contact and agreement as pending. Public visibility grants no sale or blanket commercial licence; rights and participation require their own agreement.

This manually edited guide summarizes the audited source. The original technical documentation remains the reference for commands, build requirements, exact versions and detailed evidence.
